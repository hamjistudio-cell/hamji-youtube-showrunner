# yt-idea

Never copy titles, thumbnails, scripts, or creator identity.

Use this transformation:

WINNING MECHANISM
+ USER ADVANTAGE
+ AUDIENCE PAIN/DESIRE
+ NEW PROOF/CONSTRAINT/ANGLE
= ORIGINAL VIDEO CONCEPT

## Score each idea 1-5
- Demand
- Distinctiveness
- Credibility
- Visual potential
- Emotional stakes
- Search/browse potential
- Series potential
- Production feasibility

Return:
- 10 concepts
- top 3
- one winner
- one sentence on why the winner beats the rest
