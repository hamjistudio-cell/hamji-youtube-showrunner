# cross-platform-shortform

One episode, three packages.
Do not rewrite the story unless platform constraints require it.

## TikTok
Prioritize:
- first 1 second visual/text stop
- trend-native sound or behavior when relevant
- comment prompt that can generate the next episode
- caption as context, not a duplicate of on-screen text

## Instagram Reels
Prioritize:
- strong cover that keeps the profile grid coherent
- recognizable character/IP branding
- save/share-friendly caption when applicable
- serial naming consistency

## YouTube Shorts
Prioritize:
- title clarity and curiosity
- immediate first-frame promise
- next-Short / series bridge
- searchable language when useful

## Output

TIKTOK: first-frame text, caption, CTA, cover note
REELS: cover text, caption, CTA, grid/series note
SHORTS: title, first-frame text, description line, next-video bridge

Never claim one package is guaranteed to perform on all three platforms.
