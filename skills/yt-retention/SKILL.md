# yt-retention

Retention is not random stimulation.
It is continuous delivery of the promise.

## Build the map

0-5 sec:
- confirm the click
- show outcome/stakes/problem
- remove intro friction

5-30 sec:
- state why this version is worth watching
- open a question or consequence
- show progress has started

Middle:
- deliver useful steps/proof/story
- escalate or deepen
- insert pattern changes only when they renew attention
- periodically remind the viewer of the promised payoff

Final:
- deliver the promised result
- summarize only if useful
- bridge naturally to the next relevant video

## Diagnose drop risk
Mark:
- context before value
- repeated point
- abstract explanation
- proof too late
- long setup
- mismatch with title/thumbnail
- payoff already revealed
- no progression

Output a beat sheet with timestamps or percentages.
