# ai-character-shortform

Build a CHARACTER IP, not a pile of unrelated AI clips.

## Core formula

FAMILIAR HUMAN PROBLEM
× DISTINCT CHARACTER PERSONALITY
× ONE SHORT EVENT
× VISIBLE PROGRESSION
× PAYOFF / REVERSAL
× NEXT-EPISODE BRIDGE

## Start with six anchors

1. CHARACTER — who is this character?
2. AUDIENCE — who recognizes the situation immediately?
3. PROMISE — why follow this character again tomorrow?
4. FORMAT — 9:16 duration, dialogue/no dialogue, music/TTS, camera style.
5. PRODUCTION — Flow/Veo/Kling/Runway/image-to-video/etc.
6. GOAL — discovery, follow, comments, series growth, conversion.

If some are missing, infer a provisional choice from supplied assets and label it as inference.

## Workflow

### 1 — Diagnose the channel/IP
Define:
- Core promise
- Character contradiction
- 3-5 content pillars
- 2-4 repeatable formats
- Discovery format
- Follow/return format

Example contradiction: "백수인데 누구보다 바쁘다."

### 2 — Market and outlier scan
Use `yt-market` and `yt-outlier` principles on public evidence.
Do not treat one viral clip as a market.
For short-form, compare similar platform, format and time window when possible.

### 3 — Generate 10 ORIGINAL episode ideas
Use `yt-idea` principles.
Reject clones of another animal character's exact job, line, title or look.
Choose top 3, then one winner.

### 4 — Lock the episode contract
Before scene prompts, freeze:
- one-sentence premise
- first-frame promise
- ending payoff
- duration
- dialogue/TTS/no-dialogue rule
- camera rule
- character invariant
- state-changing prop/object if any

Do not change these mid-project unless the user explicitly revises them.

### 5 — Build a character bible
Use `character-bible`.

### 6 — Build a scene-state ledger
Use `scene-continuity` before generating individual scene prompts.
Every scene must know what changed from the previous scene.

### 7 — Create production prompts
Use `flow-prompt`.
Image prompt and video-motion prompt are DIFFERENT artifacts.
Never answer a video-prompt request with an image prompt, or vice versa.

### 8 — Adapt per platform
Use `cross-platform-shortform`.

### 9 — Quality gate
Use `shortform-quality-gate`.
Return MAKE / REVISE / KILL.

## Shin-dduby preset

When the user refers to 신뚜비, use this provisional preset unless they override it:
- Species/look: fluffy white Bichon Frise, recognizable round Bichon head, dog-like body proportions.
- Character: unemployed, nosy, oddly busy; human-life satire through a Bichon's point of view.
- Core promise: "백수인데 누구보다 바쁜 참견쟁이 비숑의 인간생활 시트콤."
- Tone: cute visual × dry/real-life consequence.
- Series examples: 취업일지, 사생활, 댓글이 시키는 신뚜비.
