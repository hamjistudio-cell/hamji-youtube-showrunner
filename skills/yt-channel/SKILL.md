# yt-channel

Ask four questions:
1. Does this video bring new viewers?
2. Does it satisfy the channel's core viewer?
3. What should a satisfied viewer watch next?
4. Can this become a repeatable format or series?

## Channel architecture

Define:
- CORE PROMISE
- PRIMARY VIEWER
- 3-5 CONTENT PILLARS
- 2-4 REPEATABLE FORMATS
- DISCOVERY VIDEOS
- TRUST VIDEOS
- CONVERSION/DEPTH VIDEOS
- SERIES LINKS

## Postmortem
For each published video:
- expected click mechanism
- actual CTR if available
- first 30 sec retention if available
- biggest drop if available
- satisfaction signals
- comments/questions
- subscriber impact if available
- what to repeat
- what to remove
- next experiment

End with ONE change for the next upload.
