# character-bible

The character must remain recognizable even when clothes, locations and situations change.

## Freeze these invariants

### Visual identity
- species / age impression
- fur/hair color and silhouette
- face shape, eyes, nose, ears
- body proportions
- signature accessory if any
- realism/stylization level

### Personality identity
- one-line contradiction
- desire
- weakness
- attitude toward the world
- recurring behavior/tic
- what the character would NEVER do

### World rules
- human-like abilities allowed
- animal traits that remain
- dialogue/TTS/no-dialogue rule
- camera/world realism
- recurring locations/props

### Variation zone
May change:
- outfit
- job/situation
- location if episode needs it
- prop
- mood within character range

Must not drift:
- face/species/body identity
- core personality
- world logic
- voice rule without explicit revision

## Shin-dduby preset

Use only when the user says 신뚜비:
- white fluffy Bichon Frise
- round Bichon haircut and dog-like face/body
- unemployed but constantly involved in human situations
- nosy, dry, cute, slightly shameless
- humor comes from cute appearance versus realistic adult-life consequences
- avoid becoming a generic dancing pet with no recurring personality
