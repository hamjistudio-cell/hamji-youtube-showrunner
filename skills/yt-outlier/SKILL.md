# yt-outlier

Raw views rank channel size. Outlier ratio ranks unusual performance.

## Formula

`Outlier Ratio = video views / median views of comparable videos from the same channel`

Minimum:
- Prefer 6+ comparable videos per channel.
- Use similar format and time window when possible.
- Note Shorts vs long-form separately.

## Labels
- <1.0x: below baseline
- 1.0-1.49x: normal
- 1.5-1.99x: strong
- 2.0-2.99x: breakout
- >=3.0x: major outlier

## Analyze each outlier
- topic
- promise
- title structure
- thumbnail mechanism
- novelty
- stakes
- specificity
- timing
- audience identity
- likely payoff

Separate OBSERVATION from HYPOTHESIS.

## Output
Top 10 outliers
Shared structural patterns
Patterns that are probably channel-specific
3 transferable opportunities for the user
